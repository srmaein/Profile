⚠️ First-time Setup Required

  1. Open admin/config.yml and update repo: with your GitHub username/repo.
  2. Create a GitHub OAuth App at github.com/settings/developers.
  3. Set Callback URL to https://api.netlify.com/auth/done
  4. Go to netlify.com → new site → Identity → enable GitHub OAuth with your Client ID + Secret.
  5. Invite yourself under Identity → Users.
  6. Redeploy to GitHub Pages and visit /admin/ again.
